# 🩺 Breast Cancer Predictor

Classifies a tumor as **benign** or **malignant** from cell-nucleus measurements using Logistic Regression, with a Streamlit UI.

## Tech Stack
Python, scikit-learn, pandas, joblib, Streamlit

## Dataset
Wisconsin Breast Cancer dataset, bundled with scikit-learn (`load_breast_cancer`). No download needed.

## How to Run
```bash
pip install -r requirements.txt
python train.py
streamlit run app.py
```

## Results
Test accuracy: ~97-98% (see `train.py` output).
